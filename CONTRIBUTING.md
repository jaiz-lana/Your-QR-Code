# Berkontribusi ke Your QR Code

Terima kasih telah tertarik berkontribusi! Proyek ini dibuat agar tetap ringan, ramah HP low-end, dan gratis untuk komunitas pendidikan & UMKM.

## Aturan Dasar
1. Gunakan HTML5, CSS3, dan Vanilla JavaScript (ES modules) tanpa framework berat.
2. Pastikan setiap library CDN di-pin ke versi spesifik.
3. Jaga komentar kode singkat dan jelas dalam Bahasa Indonesia.
4. Jangan menyimpan rahasia/API key privat di kode frontend.
5. Pastikan kontras warna dan label aksesibilitas (`aria-*`, `<label>`) terpenuhi pada mode terang maupun gelap.

## Alur Kontribusi
1. Fork repositori ini.
2. Buat branch fitur baru (`git checkout -b fitur/nama-fitur`).
3. Uji perubahan Anda menggunakan daftar di `docs/daftar-uji-manual.md`.
4. Kirim Pull Request dengan deskripsi singkat perubahan Anda.
